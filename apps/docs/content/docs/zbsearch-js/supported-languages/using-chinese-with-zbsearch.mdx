---
title: Using Chinese with ZBSearch
description: Learn how to use Chinese with ZBSearch.
---
At the time of writing, ZBSearch supports Chinese (Mandarin) via a custom tokenizer, which is part of the `@zbsearch/tokenizers` package.

To get started, make sure to install all the dependencies you need:

```bash
npm i zbsearch @zbsearch/tokenizers
```

If you want to add Mandarin stop-words as well, install the `@zbsearch/stopwords` package too:

```bash
npm install @zbsearch/stopwords
```

Now you're ready to get started with ZBSearch:

```js
import { create, insert, search } from "zbsearch";
import { createTokenizer } from '@zbsearch/tokenizers/mandarin'
import { stopwords as mandarinStopwords } from "@zbsearch/stopwords/mandarin";

const db = create({
  schema: {
    name: "string",
  },
  components: {
    tokenizer: createTokenizer({
      stopWords: mandarinStopwords,
    }),
  },
});

insert(db, { name: "北京" }); // Beijing
insert(db, { name: "上海" }); // Shanghai
insert(db, { name: "广州" }); // Guangzhou
insert(db, { name: "深圳" }); // Shenzhen
insert(db, { name: "成都" }); // Chengdu
insert(db, { name: "杭州" }); // Hangzhou
insert(db, { name: "南京" }); // Nanjing
insert(db, { name: "北京大学" }); // Peking University
insert(db, { name: "上海交通大学" }); // Shanghai Jiao Tong University
insert(db, { name: "广州中医药大学" }); // Guangzhou University of Chinese Medicine

const results = search(db, {
  term: "广州",
  threshold: 0,
});

console.log(results);
```
