---
title: Using Japanese with ZBSearch
description: Learn how to use Japanese with ZBSearch.
---

At the time of writing, ZBSearch supports Japanese via a custom tokenizer, which is part of the `@zbsearch/tokenizers` package.

To get started, make sure to install all the dependencies you need:

```bash
npm i zbsearch @zbsearch/tokenizers
```

If you want to add Japanese stop-words as well, install the `@zbsearch/stopwords` package too:

```bash
npm install @zbsearch/stopwords
```

Now you're ready to get started with ZBSearch:

```js
import { create, insert, search } from "zbsearch";
import { createTokenizer } from '@zbsearch/tokenizers/japanese'
import { stopwords as japaneseStopwords } from "@zbsearch/stopwords/japanese";

const db = create({
  schema: {
    name: "string",
  },
  components: {
    tokenizer: createTokenizer({
      stopWords: japaneseStopwords,
    }),
  },
});

insert(db, { name: "東京" }); // Tokyo
insert(db, { name: "大阪" }); // Osaka
insert(db, { name: "京都" }); // Kyoto
insert(db, { name: "横浜" }); // Yokohama
insert(db, { name: "札幌" }); // Sapporo
insert(db, { name: "仙台" }); // Sendai
insert(db, { name: "広島" }); // Hiroshima
insert(db, { name: "東京大学" }); // University of Tokyo
insert(db, { name: "京都大学" }); // Kyoto University
insert(db, { name: "大阪大学" }); // Osaka University

const results = search(db, {
  term: "大阪",
  threshold: 0,
});

console.log(results);
```
