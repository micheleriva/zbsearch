<Callout title='What are stopwords?'>
The words which are generally filtered out before processing a natural language are called **stop words**. These are
actually the most common words in any language (like articles, prepositions, pronouns, conjunctions, etc) and does not
add much information to the text. Examples of a few stop words in English are “the”, “a”, “an”, “so”, “what”.
</Callout>

ZBSearch provides support for stop-words removal via the `@zbsearch/stopwords` package.

```bash
npm install @zbsearch/stopwords
```

## Enabling stop-words removal

By default, ZBSearch does not remove any stop-word, as this is intended to be an explicit action from the user. To enable stop-words removal, you can use the `stopWords` property when creating a new ZBSearch instance:

```javascript copy
import { create } from "zbsearch";

const db = create({
  schema: {
    author: "string",
    quote: "string",
  },
  components: {
    tokenizer: {
      stopWords: ["foo", "bar"], // Enable custom stop-words
    },
  },
});
```

## Using the default stop-words list

By installing the `@zbsearch/stopwords` package, you can use the default stop-words list for a given language:

```javascript copy
import { create } from "zbsearch";
import { stopwords as englishStopwords } from "@zbsearch/stopwords/english";

const db = create({
  schema: {
    author: "string",
    quote: "string",
  },
  components: {
    tokenizer: {
      stopWords: englishStopwords,
    },
  },
});
```

Using the default stop-words list is the recommended way to enable stop-words removal, as it is the most efficient way to do so.

## Extending the default stop-words list

You can always extend the default stop-words list by adding or removing words:

```javascript copy
import { create } from "zbsearch";
import { stopwords as italianStopwords } from "@zbsearch/stopwords/italian";

const db = create({
  schema: {
    author: "string",
    quote: "string",
  },
  components: {
    tokenizer: {
      stopWords: [...italianStopwords, "ciao", "buongiorno"],
    },
  },
});
```

<Callout title='Multilingual indexes'>
The zero-config [`multilingual` mode](/docs/zbsearch/supported-languages#multilingual-mode-zero-config) has no default stop-words list - there is no single language to draw one from - but you can still pass a custom `stopWords` array (or a function combining several language lists) exactly as shown above.
</Callout>
