# About this sandbox

This site is not documentation for anything real. It exists so the ZBSearch
Docusaurus plugin can be developed against a site that behaves like a genuine
one, with docs, a blog and a standalone page.

## Why a sandbox

Search is hard to unit test in isolation: it only works when indexing, bundling
and the browser all agree. Running a real Docusaurus build catches the
disagreements.
